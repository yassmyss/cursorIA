## Encontrar un símbolo o error
Para localizar una función, variable o mensaje de error concreto, proporciona su nombre exacto. Agent puede buscar coincidencias y patrones en archivos. La documentación consultada describe Instant Grep para este trabajo.
## Contexto y datos
El índice de Instant Grep se construye y consulta localmente. Esto no significa que todo uso de Agent sea local: el contenido de un archivo abierto puede incorporarse a la petición al modelo. Consulta la política de uso de datos antes de trabajar con información sensible.

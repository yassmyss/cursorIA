## Qué hace Agent
Agent combina instrucciones, herramientas y un modelo. Puede buscar archivos, editar código y ejecutar comandos de terminal. Revisa las acciones y resultados cuando delegues cambios en tu proyecto.
## Checkpoints y Git
Los checkpoints guardan estados locales de los archivos durante una sesión del agente. Sirven para recuperar cambios realizados por Agent. Están separados de Git y no sustituyen el control de versiones permanente. Usa Git para conservar el historial del proyecto.
